== Where AWS Lambda enforces the boundary

Scope the Lambda execution identity to the deployment workspace. The adapter owns the provider credential. Propagate the decision ID into the provider trace so a retry can be matched to its original authorization.

== Connection sequence

[arabic]
. Read the BoundaryKit workspace using the adapter identity.
. Cache the revision only for this session.
. Forward the provider call after evaluation.

----
curl --fail-with-body "https://api.boundarykit.com/v2/integrations" -H "X-API-Key: $BKIT_KEY" -H "X-Organization-Id: $BKIT_ORG"
----
