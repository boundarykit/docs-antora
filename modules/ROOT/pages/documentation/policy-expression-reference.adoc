= Policy expression reference
:stem: latexmath

Use this reference when reviewing a pinned policy revision or reconstructing an audit trail.

== Expression grammar

An expression returns a typed value. A policy predicate must return Bool. Missing and null are distinct. See link:#string-comparisons[String comparisons].

[source,ebnf]
----
expr = literal | field | call | expr operator expr ;
call = identifier '(' [expr {',' expr}] ')' ;
field = identifier {'.' identifier} ;
----
