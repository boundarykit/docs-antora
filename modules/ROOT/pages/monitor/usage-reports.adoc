= Usage reports
:stem: latexmath

Usage reports — record the acceptance criteria for usage reports in the workspace change log.

== Symptom

The reported state of usage reports differs between the dashboard and the latest receipt.

== First observation

Group observations by organization and revision before aggregating. A rollout can change the population halfway through an observation window.

== Decision tree

[arabic]
. Record the acceptance criteria for usage reports in the workspace change log.
. If the revision differs, split the interval at deployment time.
. If it matches, inspect a single trace before changing alert thresholds.

== Recovery evidence

Inspect the receipt for *Usage reports*. Compare its organization and revision with the values in the fixture before interpreting the result.
